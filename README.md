# HSLIT — Heathrow Slot Lease Income Token

ERC-20 smart contract deployed on the Ethereum Sepolia testnet as part of an asset tokenisation design for IFTE0007 (Decentralised Finance and Blockchain) at University College London.

## Overview

HSLIT tokenises the lease income rights derived from airport landing slots at London Heathrow. Economic rights are routed through a Special Purpose Vehicle (SPV) under a Revenue Participation Agreement (RPA) with a hypothetical slot-holding airline (Zafima Airways). Token holders acquire fractional claims on the quarterly USDC income stream generated by the slot portfolio — not ownership of the slots themselves.

## Contract Details

- **Token name:** Heathrow Slot Lease Income Token
- **Symbol:** HSLIT
- **Total supply:** 10,000,000 HSLIT (fixed at deployment)
- **Standard:** ERC-20 (OpenZeppelin)
- **Network:** Ethereum Sepolia Testnet
- **Contract address:** `0xD0Aa30C74D3E2847Ddde3a163A3c53537a7040e9`

## Key Functions

| Function | Access | Description |
|---|---|---|
| `distribute(uint256 amount)` | Servicer only | Logs a verified income distribution event on-chain |
| `updateServicer(address)` | Owner only | Replaces the servicer address (governance) |
| `burn(uint256 amount)` | Token holder | Burns tokens at RPA expiry for redemption |

## Design Notes

The `distribute()` function emits an on-chain event rather than transferring a live stablecoin, reflecting testnet constraints. In a production deployment, this function would trigger a pro-rata USDC transfer to all token holders upon servicer verification of lease income.

The servicer address represents the trusted off-chain data input — the critical centralisation point in the design, as discussed in the accompanying report.
